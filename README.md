# BasaFinder 🏡

BasaFinder is a full-stack rental housing platform where users can discover rental properties, request bookings, and manage their listings. The platform supports three roles: **Admin**, **Landlord**, and **Tenant**, each with role-specific dashboards and functionality.

## 🔗 Live Site

🌐 [Visit BasaFinder Live](https://basa-finder-client-rosy.vercel.app)

## 🖥️ Server Repository

📦 [BasaFinder Server Code](https://github.com/Mehedimid/rental-house-server)

## 🚀 Features

- 🔐 JWT-based Authentication
- 🧑‍💼 Role-based Access: Admin, Landlord, Tenant
- 🏘️ Property Listing and Filtering
- 📅 Booking Requests
- 💳 Payment Integration
- 📊 Admin Dashboard for User & Listing Management
- 📁 Modular Backend with TypeScript, Express, MongoDB

## 🛠️ Tech Stack

**Frontend:**  
- Next.js  
- TypeScript  
- Tailwind CSS  
- Redux Toolkit  
- Axios  

**Backend:**  
- Node.js  
- Express.js  
- MongoDB  
- Mongoose  
- Zod (Validation)  
- JWT, bcrypt (Auth)

## 👥 Roles & Permissions

| Role     | Capabilities |
|----------|--------------|
| Admin    | Manage users, listings, and bookings |
| Landlord | Add/edit properties, view booking requests |
| Tenant   | Browse listings, make booking requests, pay rent |
